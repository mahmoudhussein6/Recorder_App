# 🎥 Recorder - Professional Browser Screen Recorder

Recorder is a high-fidelity, browser-based screen recording application designed for professionals. Built with React and modern web technologies, it offers a seamless recording experience without the need for any plugins or external software.

![Recorder Preview](https://studiorecord.app/og-image.png)

## ✨ Features

- **🚀 Instant Recording**: Start capturing your screen with a single click directly from your browser.
- **🎙️ Audio Capture**: Toggle microphone audio to record narrations or system sound.
- **🖼️ High Fidelity**: Uses VP9 encoding for high-quality, web-optimized video.
- **💾 Easy Downloads**: Instantly preview and download your recordings in `.webm` format.
- **🛡️ Privacy First**: All recording processing happens locally in your browser. No data is sent to any server.
- **💅 Premium UI**: Modern obsidian-dark theme with glassmorphism effects and smooth animations.
- **📱 Responsive Design**: Optimized for various screen sizes.
- **✨ Splash Screen**: Engaging initial loading experience.
- **🔗 SPA Routing**: Integrated 404 "Not Found" page for a smooth user experience.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO**: [React Helmet Async](https://github.com/staylor/react-helmet-async)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Deployment**: Optimized for [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/record-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd record-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment

The project is pre-configured for deployment on Vercel.

1. Connect your repository to Vercel.
2. The `vercel.json` file handles all SPA routing automatically.
3. Your app will be live with high-performance edge delivery.
